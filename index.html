📐 Automated Domain Feature Engineering

Raw attributes (like income or balance) lack relative context. The engine computes derived ratios to capture true liquidity strain:

1. Debt-To-Income (DTI) Ratio
DTI = (Monthly Debt Payments + [Loan Amount / Term]) / (Annual Income / 12)

Lending standard ceiling is 43%. Values above this denote dangerous leverage.

2. Loan-To-Income (LTI) Ratio
LTI = Loan Amount / Annual Income

Proportional principal risk relative to annual wage capacity.

3. Delinquency Severity Index
Severity = 1.0 * Late_30d + 2.5 * Late_60d + 5.0 * Late_90d

Penalizes 90+ day charge-offs exponentially heavier than temporary 30-day slips.

4. Payment Reliability Score
Reliability = Credit History Length (Months) / (1 + 8.0 * Severity Index)

Rewards established track records while heavily discounting profiles with recent defaults.
